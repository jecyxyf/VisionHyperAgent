编码、接口接入或判断当前契约是否适用时，检查本次模块、依赖的接口及下一节中的相关变更，不能只看一行状态或仅看文件是否存在。

| 记录情况 | 对本次任务的处理 |
| --- | --- |
| 相关 API 已完成、上游所需确认有效、关联变更已同步，且记录与正文一致 | 可以据此实施，不重复采访已确认事项 |
| 相关契约仍在生成、待确认、待更新或阻塞，或关联变更尚未同步 | 暂不依据该契约实施，转需求技能处理对应的未完成事项；旧正文仍可供标明状态的查询和只读审查 |
| 进度文件或模块记录缺失、状态未核对、记录与正文不一致 | 核实本次相关基线后补充记录，不默认为可用，也不从头重做无关需求访谈 |
