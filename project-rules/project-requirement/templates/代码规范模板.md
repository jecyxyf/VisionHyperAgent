## 3. 注释规范（所有手写程序语言必须遵守）

### 3.1 内容要求

- 注释简短直接，只描述对应代码的功能，例如“读取配置”“校验输入尺寸”“释放连接”。
- 不写开发过程、修复历史、需求来源、与当前代码无关的背景或评价。
- 公共类型与接口需要说明职责、参数、返回值及失败行为；注释必须与实际代码一致。
- 不用空注释、装饰线、重复堆砌相同文字或代码翻译凑数量。

### 3.2 五行检查口径

- 每连续 **5 行非空源码**中，至少有 **1 行有效功能注释**；最多连续 4 行没有注释的代码。
- 按物理行检查，空白行不计。声明、导入、分支和括号行也属于源码，不能因换行或加空行规避。
- 独立注释和同行注释均可计入；只有注释符号而无功能说明的行不计入有效注释。
- 多行注释中包含功能说明的行可计入，单独的起止符号不计。字符串里的注释符号不是注释。
- 使用各语言合法的注释语法，不在字符串数据、模板字面量或纯数据文件中塞入假注释；必要时调整手写代码的合法组织方式。
- 纯数据、第三方和机器生成文件不作为手写源码修改；这不是对某一种程序语言的豁免。文档中的完整调用 Demo 也遵守此规则。

### 3.3 注释表达示例

以下只示范注释密度与表达，生成正式规范时换成目标项目语言的例子，不改变项目技术选型。

```python
# 读取图片数量
def count_images(images):
    count = 0
    for image in images:
        # 统计有效图片
        if image is not None:
            count += 1
    # 返回有效数量
    return count
```

```cpp
// 引入计数和数组类型
#include <cstddef>
#include <vector>

// 计算有效图片数量
std::size_t CountImages(const std::vector<bool>& flags) {
  std::size_t count = 0;
  for (bool valid : flags) {
    // 累加有效记录
    if (valid) {
      ++count;
    }
  }
  // 返回统计结果
  return count;
}
```
