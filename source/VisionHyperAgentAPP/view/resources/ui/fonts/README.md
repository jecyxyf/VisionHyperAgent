- 许可：SIL Open Font License 1.1，版权及完整许可见 [LICENSE.txt](LICENSE.txt)。
- SHA-256：`b76b0433203017ca80401b2ee0dd69350349871c4b19d504c34dbdd80541690a`。
- 在 `MainWindow.slint` 中导入，随 Slint 编译嵌入可执行文件。
