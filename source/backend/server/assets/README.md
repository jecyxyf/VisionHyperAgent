选用用户提供的 `c52b017b-0b4a-43ef-bc5d-f031141c1bc2.png` 中的 **7 号**，即第二行第二列。
图案直接取自原图，没有重新绘制；仅裁掉编号和外围白底、处理外轮廓的透明抗锯齿，并等比导出。

| 文件 | 用途 |
| --- | --- |
| `app-icon-source.png` | 196×196 RGBA 原始分辨率裁切素材，含透明留白；后续导出的唯一来源 |
| `tray-icon.png` | 64×64 RGBA，嵌入 Linux / Windows 宿主的系统托盘 |
| `app-icon.ico` | 16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256px，嵌入 Windows EXE 图标资源 |
| `export_icons.py` | 从裁切素材重新导出 PNG / ICO 的开发辅助脚本 |

原图尺寸为 1448×1086，图案区域为 `(341, 296)–(521, 473)`（左上包含、右下不包含）。
原图 SHA256：`84cf4e19014453615ed3acd1c6693230bd6c6e2b129959964a37025c75d0aa39`。
256px 帧由裁切素材缩放得到，并非新增高清细节。

如需重新导出，在已安装 Pillow 的 Python 环境中执行：

```bash
python3 source/backend/server/assets/export_icons.py
```

Pillow 仅供素材导出使用，不是应用运行或 Rust 编译的依赖。
图标已编译进可执行文件，修改后需要重新构建并重启宿主；浏览器刷新不会更新系统托盘图标。
