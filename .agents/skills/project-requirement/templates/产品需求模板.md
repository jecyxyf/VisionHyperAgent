# <项目名称> 产品需求文档

> 本模板用 ImageBatch 图片批处理工具演示产品需求的表达方式。只写用户目标、行为、体验和验收，不写技术选型、架构、源码、协议或实现细节。根据访谈替换示例，成品移除本段模板说明。

## 1. 产品定位与目标

帮助需要重复处理图片的用户一次完成多张图片的尺寸调整和效果处理，减少逐张操作，并清楚看到处理进度与结果。

| 目标 | 用户价值 | 判断标准 |
| --- | --- | --- |
| 减少重复操作 | 一次设置应用到多张图片 | 同一批图片可以使用同一组处理设置 |
| 结果可理解 | 用户知道哪些完成、哪些失败 | 界面显示进度、最终结果和可理解的失败原因 |
| 保护原文件 | 用户可以保留原图并重新处理 | 处理结果不覆盖原始图片 |

## 2. 用户与使用场景

| 用户 | 场景 | 期望完成的事情 |
| --- | --- | --- |
| 内容编辑 | 发布前统一图片尺寸 | 选入图片、统一设置尺寸、获取可用结果 |
| 普通用户 | 对一组照片进行相同处理 | 能预览效果、批量处理并找到保存位置 |

## 3. 产品范围与优先级

| 范围 | 内容 | 优先级 |
| --- | --- | --- |
| 本期包含 | 图片导入、处理设置、批量处理、结果查看、保存与恢复工作内容 | 必须 |
| 可选能力 | 增加其他处理效果 | 后续按需求确认 |
| 本期不包含 | 云端同步、账号体系、多人协作 | 不纳入本期 |

## 4. 功能需求

| 功能 | 用户操作 | 产品行为 | 验收标准 |
| --- | --- | --- | --- |
| 导入图片 | 选择多张图片 | 显示已选图片，无法使用的文件说明原因 | 有效图片进入列表；失败文件有明确提示 |
| 设置处理内容 | 设置目标宽高和需要的效果 | 展示当前设置；不合法的输入提示修正 | 无效尺寸不能开始处理，用户能够知道如何修改 |
| 批量处理 | 点击开始 | 按当前设置处理整批图片，展示进度 | 显示已完成数量与总数，结束后展示结果 |
| 取消处理 | 点击取消 | 显示取消请求，停止后说明实际完成情况 | 不把“已请求取消”直接显示为“全部未处理”，保留已有结果 |
| 查看结果 | 选择已完成的图片 | 查看结果及其保存位置 | 能区分原图与处理结果，并找到输出文件 |
| 保存与恢复 | 保存工作内容后再次打开 | 恢复图片选择和处理设置，不自动开始处理 | 用户检查设置后可以主动继续处理 |

## 5. 用户流程与交互

```text
选择图片 → 设置处理内容 → 检查设置 → 开始处理 → 查看结果
                              │
                              └── 修改设置后重新检查

处理过程中请求取消 → 等待停止或完成 → 查看实际结果
```

| 交互状态 | 用户看到的内容 | 可以进行的操作 |
| --- | --- | --- |
| 未开始 | 图片列表和处理设置 | 添加图片、修改设置、开始处理 |
| 处理中 | 当前进度与处理提示 | 查看进度、请求取消 |
| 已结束 | 成功、失败或取消结果 | 查看结果、调整设置后再次处理 |

## 6. 业务规则与异常反馈

| 情况 | 处理规则 | 用户反馈 |
| --- | --- | --- |
| 没有选择图片 | 不开始处理 | 提示先添加图片 |
| 处理设置无效 | 要求修正后再开始 | 明确指出需要修改的输入 |
| 部分图片处理失败 | 已成功完成的结果保留 | 说明哪些完成、失败原因及可采取的操作 |
| 保存位置不可用 | 不把未保存结果当作成功 | 提示检查或更换保存位置 |
| 恢复后原始图片找不到 | 保留可恢复的工作内容 | 标明缺失图片，提示用户处理 |

## 7. 体验与使用约束

| 项目 | 产品要求 | 验收方式 |
| --- | --- | --- |
| 可理解性 | 使用用户能理解的提示，不展示难懂的内部错误 | 用户可根据提示完成下一步操作 |
| 过程反馈 | 耗时操作保持可见反馈，不能一直没有状态提示 | 操作时能够看到进度或明确的等待说明 |
| 文件保护 | 不覆盖原始图片 | 处理前后原图保持不变 |
| 隐私 | 不擅自上传用户图片 | 涉及对外分享时由用户明确选择 |

此处按访谈补充目标用户的使用环境、支持的图片类型和可量化的体验目标，不写实现方案。

## 8. 验收场景

| 场景 | 前提 | 用户操作 | 预期结果 |
| --- | --- | --- | --- |
| 正常处理 | 已添加有效图片并设置有效尺寸 | 开始处理 | 输出符合设置的结果，原图不变 |
| 无效输入 | 尚未选择图片 | 尝试开始 | 提示先选择图片，不进入处理状态 |
| 取消处理 | 任务尚在进行 | 请求取消 | 提示请求已提交，最终展示实际停止或完成情况 |
| 恢复工作 | 已保存一份工作内容 | 再次打开 | 恢复选择与设置，等待用户主动开始 |
