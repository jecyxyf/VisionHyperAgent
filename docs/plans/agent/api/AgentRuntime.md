## 1. 类型定义与关系

### 1.1 定义

**说明**：一个 Agent 实例的后台运行协调者。负责驱动生命周期、接收宿主命令、推进各功能模块的状态及持续处理 Codex 事件；不成为会话、任务和工具规则的第二个拥有者。

本类只持有 Runtime 侧 AgentTransport，不持有 Host 侧端点或宿主 Agent 对象。它报告后台初始化、运行及结束结果；整体 AgentState 由 Agent 的生命周期协调逻辑综合两端结果维护。

**类型声明**：

```rust
pub(crate) struct AgentRuntime { /* 私有实现 */ }
```

#### 4.2.1 `run(context)`

**说明**：在后台运行上下文中完成初始化，并持续驱动命令、事件和退出流程。

**定义**：

```rust
pub(crate) async fn run(self, context: ZmqContext) -> Result<(), AgentError>
```

**参数**：

| 参数名 | 类型 | 说明 | 约束 |
| --- | --- | --- | --- |
| context | ZmqContext | 当前 Agent 链路的共享上下文句柄 | 与 Host 端关联同一个底层 Context，不在此创建独立替代上下文 |

**返回值**：后台运行结束的结果；该 future 不应被当作只等待初始化完成的调用，也不能单独证明 Host 端已经关闭。

**错误**：

| 错误或失败状态 | 触发条件 | 失败后的状态 | 调用方处理 |
| --- | --- | --- | --- |
| `Backend / Transport / Io` | 初始化、上游请求或内部通信失败 | 保留实际状态及错误，不假定已经回滚 | 由运行核心向宿主明确反馈 |

**备注**：
- Agent.initialize() 应等待独立的初始化结果，不能等待 run 整个生命周期结束。
- context 由 Agent 初始化阶段的统一装配提供，与 Host 端共享同一个底层 Context；本类启动其 Runtime 端通信对象，不自行创建另一个不关联的 Context。
- 本类只报告后台初始化结果；整体 Ready 由 Agent 综合两端及 Codex 的状态确认，不依赖先完成一次远端模型请求。
- 一个 Manager 不对应一个线程；项目侧线程通信沿用已确认的 ZeroMQ inproc 边界。

#### 4.2.2 `handle_command(received)`

**说明**：分派内部类型化命令，将具体规则交给所属功能模块处理。

**定义**：

```rust
pub(crate) async fn handle_command(&mut self, received: ReceivedAgentCommand) -> Result<(), AgentError>
```

**参数**：

| 参数名 | 类型 | 说明 | 约束 |
| --- | --- | --- | --- |
| received | ReceivedAgentCommand | CommandId 与类型化 AgentCommand | 保留通信关联，不用 TaskId 或当前会话替代 |

**返回值**：本次分派结果；对话请求的受理与完成仍分别报告。

具体操作的成功数据或错误通过 AgentTransport.respond 回传到原 CommandId。本方法的分派完成不能替代接口操作结果，也不能等待整条模型回复结束才发出提交请求的响应。

**错误**：

| 错误或失败状态 | 触发条件 | 失败后的状态 | 调用方处理 |
| --- | --- | --- | --- |
| `InvalidState / InvalidInput` | 状态不允许该命令或命令内容不合法 | 不执行对应动作 | 向原调用方返回错误 |
| `Backend / Transport / Io` | 初始化、上游请求或内部通信失败 | 保留实际状态及错误，不假定已经回滚 | 由运行核心向宿主明确反馈 |

**备注**：
- 普通对话提交进入 TaskManager 的等待队列；取消、工具结果、状态查询和关闭控制不能排在该队列后面。
- 不能在处理一个长请求时停止读取事件，导致工具请求无法交给宿主或取消无法生效。
- 需要等待上游的操作应保留原 CommandId 后安排到合适的异步执行路径；不能持有整个 Runtime 的独占状态或锁跨越长时间等待，具体任务与句柄组织仍须在实现前核查。

## 5. 事件与消息处理

### 5.1 事件与通知

| 名称 | 载荷类型 | 触发条件 | 说明 |
| --- | --- | --- | --- |
| 后台阶段结果 | 内部初始化／运行／结束报告 | 本后台发生阶段变化 | 交给 Agent 生命周期协调，不直接宣称整个 Agent 已关闭 |
| 功能事件 | AgentEvent 的业务事件 | 功能模块产生已确认变化 | 经 Runtime 侧 Transport 汇入统一出口；整体 StateChanged 不由本类独立推断 |

### 5.2 消息处理与回调

Runtime 是业务命令处理与上游事件处理的协调边界。命令接收、响应关联和事件投递交给 AgentTransport；后台侧由 ZmqServer 持有端点，宿主侧由 ZmqClient 持有端点，两类复用驱动模块公共实现并共享底层 Context。Runtime 不直接操作角色驱动或 Socket。Codex 内部既有类型化通道保持不变，不把项目 ZMQ 包进其内部，也不把命令传输缓冲当作任务队列。

### 6.2 枚举与嵌套类型

#### 6.2.1 `AgentCommand`

库内部命令类型，不对宿主暴露传输细节，不包含 Slint 对象或业务执行器的任意指针。完整载荷结构与编码尚待确认。

AgentCommand 表达操作本身；通信层用 ReceivedAgentCommand 增加 CommandId。线协议中不能包含本地回复通道、future、闭包或指针。

| 成员 | 类型／取值 | 说明 |
| --- | --- | --- |
| 生命周期控制 | 初始化／关闭请求 | 与普通用户请求队列分离 |
| 会话命令 | 创建／列表／读取／历史／恢复 | 使用 SessionManager 定义的输入输出 |
| 对话请求命令 | 提交／查询／取消／重试 | 队列与状态仍属于 TaskManager |
| 技能命令 | 目录查询／刷新 | 使用 SkillManager 的受控来源 |
| 工具结果命令 | ToolCallId 与 ToolResult | 回传原请求，不加入普通等待队列 |

#### 6.2.2 `请求关联数据`

内部关联信息跟随相应的功能模块管理，Runtime 驱动时必须明确区分以下标识，不能用“当前项”替代。

| 成员 | 类型／取值 | 说明 |
| --- | --- | --- |
| SessionId | 会话 | 映射 Codex thread ID |
| TaskId | 用户请求 | 排队时已经存在，发起后关联 turn ID |
| ToolCallId | 宿主工具调用 | 映射上游 call_id 及原始服务端请求 ID |
| CommandId | 一次接口调用 | 由通信层管理，不能与 TaskId 或 ToolCallId 混用 |

#### 6.2.3 `AgentCommandResult`

Runtime 回传的操作结果封装，载荷使用各功能模块已经定义的数据类型，不另建一套会话、任务或工具结果。候选结果包括 SessionInfo、SessionPage、HistoryPage、TaskId、TaskInfo、SkillCatalog，以及不携带数据的完成结果；完整变体与通信编码仍待确认。失败通过 Result 中的 AgentError 表达，不用空结果伪装成功。

## 7. 使用示例与约束

### 7.1 使用示例

内部运行顺序示意：

```text
Agent 构造并准备功能句柄
→ 后台启动 Runtime
→ 初始化 CodexAdapter 与受控资源
→ 回报初始化结果
→ 持续接收命令和上游事件
→ 由 TaskManager 选择下一条请求
→ 工具请求交给宿主，结果经控制通道回传
→ 按真实结果更新请求状态
→ 接到关闭请求后收尾并报告结束
```

这不是已验证的线程实现，不指定新的框架或依赖。

### 7.2 使用约束

- 不同 Manager 通过 AgentTransport 共享运行上下文，不共享一组可以跨线程随意操作的 ZMQ Socket；Runtime 不重复实现驱动收发和消息关联。
- 同一功能的状态只维护一次；只读快照不拥有改变事实的权限。
- 本类的局部运行阶段不是整体 AgentState 的副本。Host 通信失败、后台停止与最终资源释放由 Agent 生命周期协调逻辑汇总，不能让多个模块各自覆盖整体状态。
- 事件消费不能因同步等待一个响应而停滞；具体背压策略、容量和调度公平性待确认。
- 不将原始协议错误、KEY 或完整配置作为对外事件载荷。
- 不依赖主窗口、控件或 Slint 事件循环；界面关闭的协调由宿主通过显式接口完成。

**待确认事项：**

- 生命周期状态转换、重复初始化、并发控制与失败重建规则。
- 关闭时限、未完成请求与宿主工具的收尾策略。
- 通信层的命令编码、控制与数据通道、容量及压力行为见 AgentTransport；本类只补充与生命周期和任务驱动相关的要求。
