## 用户已确认的核心结论

- 产品定位为视觉数据标注与训练工具，Agent 主导并辅助人的工作。
- 首版任务为实例分割，首版不接入 Segment Anything 等自动预标注模型。
- 主流程为导入图片、描述目标、生成并确认规则、人工标注、生成数据集、训练、评估和新图推理。
- 每次执行前 Agent 必须用自然语言说明阶段计划和参数，经用户确认后执行；不使用计划卡片。
- 首版不内置模型服务，模型服务由用户配置；密钥只保存在后端私有配置。
- 32GB 内存、16GB 显存作为首版 GPU 验收基准；无 GPU 时项目、图片、标注和 Agent 对话仍可用。
- Windows 10/11 输出 `bin/win/` 下绿色 ZIP；Linux 输出 `bin/linux/` 绿色目录，不再二次压缩。
- 浏览器关闭不退出后台；托盘退出负责回收 Codex、ML Worker 和应用拥有的进程树。
