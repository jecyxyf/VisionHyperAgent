# VisionHyperAgent 产品需求文档

## 1. 产品定位与目标

VisionHyperAgent 是一款面向所有用户的视觉数据标注与训练工具。用户用自然语言描述识别目标，Agent 主导需求澄清、规则生成、标注建议、训练建议和问题分析；用户通过自然语言确认阶段计划、完成实例标注、监督训练结果并测试模型效果。

| 目标 | 用户价值 | 判断标准 |
| --- | --- | --- |
| 完整闭环 | 用户从一批图片开始，最终得到可测试的实例分割模型 | 能连续完成导入、标注、训练、评估和新图片测试 |
| 降低使用门槛 | 不要求用户具备算法开发经验 | 用户可以用自然语言描述目标并理解 Agent 的计划与结果 |
| 降低标注理解成本 | Agent 生成规则并解释标注重点、易混淆边界和类别定义 | 用户知道每张图片应该标什么、不标什么 |
| 保持过程可信 | 用户知道 Agent 要做什么、正在做什么、结果是否可用 | 每个阶段先展示计划，执行中可见状态，结束后可追溯 |
| 保护用户数据 | 原图、标注、模型和配置默认留在本地 | Agent 不静默覆盖用户数据，不主动外传训练数据 |
| 支持小样本体验 | 即使数据很少也能继续体验流程 | 不用固定数据量阻止实验训练，但明确提示效果风险 |

## 2. 用户与使用场景

产品面向所有人开放，不按行业、职业或技术背景设置使用门槛。以下用户仅作为典型场景分层，不限制产品入口。

| 用户 | 场景 | 期望完成的事情 |
| --- | --- | --- |
| 首次接触视觉模型的用户 | 只有一批图片和一句目标描述 | 在 Agent 引导下理解需要标注什么，并跑通训练测试流程 |
| 工业质检用户 | 缺陷、异物、外观异常检测 | 描述缺陷特征，形成标注规则，训练并比较候选模型 |
| 科研实验用户 | 小样本实例分割实验 | 快速形成数据集版本，比较不同训练参数下的效果 |
| 批量数据整理用户 | 大量图片标注与复核 | 通过规则和状态筛选组织标注工作，逐步形成训练数据 |
| 模型验证用户 | 用新图片判断模型是否可用 | 查看遮罩、类别、置信度，并对比不同候选模型 |

## 3. 产品范围与优先级

| 范围 | 内容 | 优先级 |
| --- | --- | --- |
| 首版任务 | 实例分割：每个目标包含类别、独立实例和像素级遮罩 | 必须 |
| 首版主线 | 导入图片 → 描述目标 → Agent 追问 → 确认标注规则 → 人工实例标注 → 形成数据集 → Agent 建议参数 → 用户确认训练 → 查看评估 → 测试新图片 | 必须 |
| 交付口径 | 完整闭环最小可用版：每个环节真实可用，不堆叠高级管理能力 | 必须 |
| 项目与图片 | 项目创建、图片导入、图片状态查看、无效文件提示 | 必须 |
| Agent 协作 | 自然语言追问、阶段执行计划、参数说明、执行状态、失败原因和执行记录 | 必须 |
| 标注能力 | 实例遮罩绘制、编辑、撤销重做、类别管理、逐图确认 | 必须 |
| 数据集能力 | 由已确认标注生成数据集版本，并展示数据质量摘要 | 必须 |
| 训练与评估 | Agent 建议参数，用户确认后训练，展示指标和失败案例 | 必须 |
| 模型测试 | 使用新图片查看实例遮罩、类别和置信度，比较候选模型 | 必须 |
| 后续扩展 | 分类、目标检测、Segment Anything 等辅助预标注模型、模型部署导出、多模型格式、团队协作、云端同步 | 后续 |
| 首版不包含 | 离线部署导出、公开数据集格式导出、Segment Anything 等辅助预标注模型、账号体系、多人协同、在线 SaaS、公网访问、复杂权限管理 | 不纳入 |

## 4. 功能需求

### 4.1 项目与图片管理

| 功能 | 用户操作 | 产品行为 | 验收标准 |
| --- | --- | --- | --- |
| 创建项目 | 输入项目名称和说明 | 创建独立项目空间，保存图片、标注、数据集、训练记录和测试记录 | 不同项目数据互不混淆 |
| 导入图片 | 选择一张或多张图片 | 检查文件可用性并加入项目 | 有效图片进入列表，无效文件说明原因 |
| 查看图片 | 浏览项目图片 | 展示缩略图、标注状态、实例数量和是否已确认 | 用户能找到未处理、待确认和已完成图片 |
| 删除图片 | 删除项目内图片 | 删除前说明影响，不静默连带删除用户手工标注以外的重要数据 | 删除结果可理解，训练数据来源同步更新 |
| 保护原图 | 编辑标注或执行 Agent 任务 | 不修改原始图片文件 | 标注结果独立保存，原图内容保持不变 |

### 4.2 目标描述与标注规则

| 功能 | 用户操作 | 产品行为 | 验收标准 |
| --- | --- | --- | --- |
| 描述识别目标 | 用自然语言说明要识别的对象、外观和排除条件 | Agent 解析目标，并指出缺失或模糊信息 | 用户能知道哪些信息会影响标注质量 |
| Agent 追问 | 回答目标外观、类别差异、背景、光照、尺寸等问题 | Agent 根据回答更新理解，并判断是否足够开始生成规则 | 追问聚焦关键缺口，不无限阻塞流程 |
| 生成标注规则 | 请求 Agent 生成规则 | 用自然语言说明类别、目标特征、易混淆点、排除条件和适用范围 | 规则能指导人工标注和分类 |
| 确认规则 | 通过自然语言修改并确认规则 | Agent 复述最终规则，记录确认版本 | 未确认规则不作为训练数据生成依据 |
| 管理规则版本 | 继续对话或修改目标描述 | 生成新规则版本，旧版本标记状态 | 能追溯规则变化，不混淆有效版本 |
| 处理规则冲突 | 描述之间出现矛盾 | Agent 指出冲突并请求用户选择 | 不静默选择相互矛盾的标注标准 |

### 4.3 自然语言执行计划

| 功能 | 用户操作 | 产品行为 | 验收标准 |
| --- | --- | --- | --- |
| 生成阶段计划 | 让 Agent 执行一个阶段任务 | Agent 用自然语言说明阶段目标、步骤、参数、影响范围、预计耗时、风险和不会执行的操作 | 用户不需要理解内部机制即可判断是否允许执行 |
| 调整计划 | 用自然语言修改参数或步骤 | Agent 复述调整后的最终计划 | 参数变化后不沿用旧确认 |
| 确认执行 | 明确表达同意执行 | Agent 只执行已确认的阶段计划 | 讨论或提问不触发执行 |
| 连续执行 | 确认一个阶段计划 | 阶段内步骤连续执行，减少重复确认 | 中途不无故暂停，也不偏离计划 |
| 处理计划变更 | Agent 发现需要额外步骤或参数调整 | 停止执行并重新说明新计划 | 偏离原计划必须获得新的确认 |
| 查看执行记录 | 回看已执行任务 | 展示确认过的计划、实际步骤、参数、结果和异常 | 用户能追溯 Agent 做过什么 |
| 终止任务 | 请求停止当前阶段 | 停止后续动作，汇报已完成、未完成和失败内容 | 不把取消请求误报为全部失败或全部完成 |

### 4.4 Agent 标注辅助与批量管理

| 功能 | 用户操作 | 产品行为 | 验收标准 |
| --- | --- | --- | --- |
| 生成标注建议 | 请求 Agent 解释当前规则 | 说明标注重点、类别边界、排除条件和容易误判的情况 | 首版不自动生成实例遮罩，不接入 Segment Anything 类模型 |
| 批量状态管理 | 按状态筛选图片 | 支持未标注、标注中、已确认、有异常等状态筛选和统计 | 用户能按批次推进标注工作 |
| 批量确认 | 选择多张已检查图片执行确认 | 仅确认用户明确选择的图片和标注 | 未确认标注不进入数据集 |
| 保护人工标注 | 继续 Agent 对话或批量操作 | 不覆盖用户手工标注 | Agent 建议不直接变成标注结果 |
| 处理无目标图片 | 标记不含目标的图片 | 保留为无实例样本或排除出数据集，由用户选择 | 不把未处理图片误当作无目标样本 |
| 处理问题图片 | 对损坏、重复或异常图片执行排除 | 从数据集候选中排除并记录原因 | 项目原文件不被破坏 |

### 4.5 实例分割标注

| 功能 | 用户操作 | 产品行为 | 验收标准 |
| --- | --- | --- | --- |
| 绘制遮罩 | 使用画笔、多边形或擦除工具 | 分层展示原图、已确认遮罩、当前绘制路径和控制点 | 用户能精确表达目标边界 |
| 编辑实例 | 选择、移动、调整、删除实例遮罩 | 每个目标保持独立实例和类别 | 重叠、相邻目标不互相污染 |
| 管理类别 | 新增、修改、合并类别 | 同步提示对现有标注和规则的影响 | 类别含义一致，不产生同名不同义 |
| 撤销重做 | 撤销或恢复编辑操作 | 只影响当前图片的编辑序列 | 至少支持 50 步，不破坏原图 |
| 缩放平移 | 缩放、拖拽查看大图 | 保持遮罩与原图对齐 | 4K 图片编辑时操作连续、不明显卡顿 |
| 逐图确认 | 确认单张图片标注 | 将图片从待处理改为已确认 | 只有已确认标注能进入数据集版本 |
| 质量提示 | 查看标注质量摘要 | 提示遮罩过小、类别不均衡、未确认图片和疑似漏标 | 用户能判断数据是否值得训练 |

### 4.6 数据集生成

| 功能 | 用户操作 | 产品行为 | 验收标准 |
| --- | --- | --- | --- |
| 生成数据集版本 | 从已确认标注创建数据集 | 固定图片范围、标注版本、类别和规则版本 | 后续训练能追溯所用数据 |
| 查看数据摘要 | 查看数据集统计 | 展示图片数、实例数、类别分布、图片尺寸和缺失情况 | 用户能发现明显不均衡或数据错误 |
| 更新数据集 | 标注变化后重新生成 | 创建新版本，不覆盖旧版本 | 训练记录仍能对应旧数据版本 |
| 排除问题数据 | 移除指定图片或标注 | 从新版本排除，不破坏项目原始记录 | 排除原因可追溯 |
| 数据集使用范围 | 使用项目内数据集 | 首版仅供本项目训练、评估和推理使用，不提供公开格式导出 | 内部数据结构可完整支撑闭环 |
| 小样本提示 | 数据量较少时继续生成 | 允许生成并标注为实验数据集 | 明确提示训练效果可能不稳定 |

### 4.7 训练建议与执行

| 功能 | 用户操作 | 产品行为 | 验收标准 |
| --- | --- | --- | --- |
| 生成训练建议 | 请求 Agent 分析数据集 | 用自然语言说明推荐模型、训练参数、数据增强、风险和预期现象 | 用户能理解为什么推荐这些参数 |
| 调整参数 | 用自然语言修改轮数、批大小、阈值等参数 | Agent 复述最终参数并解释影响 | 不使用用户未确认的参数组合 |
| 发起实验训练 | 确认训练计划 | 启动训练并显示阶段、进度、耗时和当前指标 | 有可用数据即可尝试，不用固定数量门槛阻止体验 |
| 查看训练进度 | 训练期间查看任务 | 持续展示状态、指标、日志摘要和剩余时间估计 | 关闭界面后任务继续，重新打开可恢复查看 |
| 停止训练 | 请求停止 | 停止后续轮次并保留可用中间结果 | 明确说明停止时已完成到哪一步 |
| 处理资源不足 | 在缺少 GPU 或资源紧张时发起训练或推理 | 提示当前设备未满足性能验收基准，并说明可用的基础功能 | 不把资源问题误报为模型效果差 |
| 登记训练结果 | 训练完成后查看结果 | 保存数据集版本、训练参数、指标和模型候选 | 不同候选模型可比较和复现 |

### 4.8 评估与模型候选

| 功能 | 用户操作 | 产品行为 | 验收标准 |
| --- | --- | --- | --- |
| 查看整体指标 | 打开训练结果 | 用可理解语言解释分割指标、类别指标和数据覆盖情况 | 用户知道模型整体表现和薄弱类别 |
| 查看失败案例 | 浏览误检、漏检和边界差的结果 | 展示原图、参考遮罩、预测遮罩和差异说明 | 用户能判断失败类型和下一步改法 |
| 获取改进建议 | 请求 Agent 分析评估结果 | 建议补数据、改规则、调参数或重新划分数据 | 建议对应明确证据，不只给通用套话 |
| 比较候选模型 | 选择多次训练结果 | 展示指标、测试结论和差异摘要 | 用户能选择当前优先使用的候选模型 |
| 标记模型状态 | 设置候选、备选或废弃 | 保留记录但不影响当前选择 | 不自动删除历史模型 |

### 4.9 新图片测试

| 功能 | 用户操作 | 产品行为 | 验收标准 |
| --- | --- | --- | --- |
| 测试新图片 | 选择一张或多张未训练图片 | 使用当前候选模型输出实例遮罩、类别和置信度 | 用户能直观判断模型是否识别目标 |
| 对比候选模型 | 用不同候选模型测试同一批图片 | 展示结果差异和关键指标摘要 | 用户能比较效果，不需要手工整理文件 |
| 保存测试结论 | 记录本次测试判断 | 保存测试图片、模型、结果和用户结论 | 后续改进和模型选择可引用测试记录 |
| 导出测试结果 | 保存可视化结果 | 输出带遮罩和置信度的图片或结果文件 | 结果能对应原图、类别和实例编号 |
| 处理测试失败 | 查看无法测试的原因 | 说明模型、数据或资源问题 | 用户知道是模型问题还是使用问题 |

### 4.10 模型服务配置

| 功能 | 用户操作 | 产品行为 | 验收标准 |
| --- | --- | --- | --- |
| 配置模型服务 | 填写服务地址、密钥、模型和默认能力 | 首版不内置模型服务，由用户自行配置；配置保存为本地私有数据，不在界面完整回显密钥 | 密钥不进入日志、交付包或明文展示 |
| 限定服务用途 | 查看 Agent 能力说明 | 首版模型服务用于自然语言理解、规则生成、参数建议和问题分析，不用于自动分割预标注 | 不因配置了模型服务就承诺 Segment Anything 能力 |
| 选择模型 | 在对话区选择模型和 Effort | 展示当前可用模型能力 | 不支持图片或当前任务的组合有明确提示 |
| 校验配置 | 保存前检查配置 | 指出无效地址、重复模型和缺失能力 | 不让用户在训练中途才发现基础配置错误 |
| 修复配置失败 | 根据提示修改配置 | 保留历史会话和项目数据 | 配置失败不导致项目数据丢失 |

### 4.11 桌面运行与生命周期

| 功能 | 用户操作 | 产品行为 | 验收标准 |
| --- | --- | --- | --- |
| 启动应用 | 解压绿色包并运行主程序 | 显示系统托盘图标，自动打开本地界面 | 无需安装；启动后用户能进入主界面 |
| 找回界面 | 点击托盘图标或打开界面入口 | 打开或聚焦已有界面 | 浏览器关闭后仍能重新进入 |
| 关闭网页 | 关闭浏览器标签或窗口 | 后台任务继续运行 | 训练、Agent 任务和应用状态不因网页关闭丢失 |
| 退出应用 | 使用托盘退出 | 停止任务和 Agent 运行环境后退出 | 不遗留应用拥有的后台进程 |
| 异常退出 | 主程序意外停止 | 下次启动检查数据与任务完整性 | 不把损坏数据当作已确认数据 |

## 5. 用户流程与交互

用户的首版主流程是：

启动应用 → 创建项目并导入图片 → 用自然语言描述识别目标 → Agent 追问并生成标注规则 → 用户确认规则 → 用户完成实例分割标注并逐图确认 → 生成数据集版本 → Agent 给出训练参数建议 → 用户确认阶段计划 → 启动训练 → 查看评估结果和失败案例 → 用新图片测试候选模型 → 保存测试结论。

| 交互状态 | 用户看到的内容 | 可以进行的操作 |
| --- | --- | --- |
| 未开始 | 项目、图片、Agent 和历史入口 | 创建项目、导入图片、描述目标 |
| 需要补充 | Agent 的自然语言追问和缺失信息摘要 | 补充答案、跳过非关键项、让 Agent 继续 |
| 待确认 | Agent 的阶段计划、规则版本或训练参数 | 继续讨论、调整参数、确认执行、拒绝执行 |
| 处理中 | 阶段目标、当前步骤、进度、耗时和状态 | 查看过程、继续其他操作、请求停止 |
| 待修正 | 未完成标注、错误标注、失败案例和异常数据 | 编辑遮罩、调整类别、重新确认 |
| 已结束 | 成功、失败、取消、指标和结果入口 | 查看结果、测试模型、发起下一阶段 |

## 6. 业务规则与异常反馈

| 情况 | 处理规则 | 用户反馈 |
| --- | --- | --- |
| 目标描述模糊 | Agent 先追问关键信息，不直接生成不可靠规则 | 说明缺少什么信息、为什么重要 |
| 规则冲突 | 请求用户选择，不静默合并矛盾 | 指出冲突内容和可选处理方式 |
| 未确认执行计划 | 不开始执行 | 等待用户明确确认 |
| 计划中途变更 | 停止扩展执行，重新提交计划 | 说明新增步骤、参数和影响 |
| Agent 服务不可用 | 界面和本地项目仍可打开 | 提示可修复原因，保存未发送内容 |
| 请求自动预标注 | 说明首版不接入 Segment Anything 等辅助预标注模型 | 引导用户按规则完成人工标注，并说明后续版本再评估 |
| 文件不可用 | 不把文件加入有效数据 | 标明具体文件和恢复建议 |
| 部分图片处理失败 | 保留成功结果和失败清单 | 支持失败项单独重试或转人工 |
| 覆盖人工标注 | 禁止静默覆盖 | Agent 只能提供建议，不能直接修改用户标注 |
| 标注数量少 | 允许生成数据集和实验训练 | 提示小样本风险和建议补充方向 |
| 无 GPU 或资源不足 | 项目、图片、标注和 Agent 对话仍可用；训练与推理不承诺可用 | 明确提示缺少满足验收基准的 GPU，不把资源问题误报为算法效果差 |
| 训练失败 | 保留数据集、参数、日志摘要和失败原因 | 用户能根据提示修复后重试 |
| 任务取消 | 区分已请求、已停止和实际完成内容 | 汇报完成数量、未处理数量和保留结果 |
| 应用异常退出 | 下次启动执行完整性检查 | 标记待恢复任务和可疑数据 |

## 7. 体验与使用约束

| 项目 | 产品要求 | 验收方式 |
| --- | --- | --- |
| 自然语言优先 | 目标理解、规则确认、阶段计划和参数调整均支持自然语言完成 | 用户不需要学习参数表单才能推进主流程 |
| 可理解反馈 | 指标、风险和错误说明面向普通用户解释 | 用户能判断下一步该做什么 |
| 过程可见 | 耗时任务持续显示状态和进度 | 用户不面对无反馈的长等待 |
| 可恢复 | 刷新页面、关闭网页或重启应用后尽量恢复上下文 | 项目、会话、任务状态和训练记录不意外丢失 |
| 本地数据 | 原图、标注、数据集、模型和配置默认保存在本地 | 外传或导出必须由用户明确选择 |
| 凭据安全 | 模型密钥不完整回显，不写入日志和交付包 | 配置、日志和发布包检查不泄漏密钥 |
| 绿色交付 | Windows 版输出到 bin/win/ 并提供 zip 压缩包；Linux 版输出到 bin/linux/，该目录本身就是绿色软件目录，不再二次压缩 | Windows 解压后可直接启动；Linux 直接进入 bin/linux/ 启动 |
| 平台范围 | 首版承诺 Windows 和 Linux；macOS 不纳入首版验收 | 按已承诺平台完成启动、运行和退出验收 |
| 性能验收基准 | Windows 10/11、Linux 主流发行版、32GB 内存、16GB 显存 | 在该配置设备上完成导入、标注、训练、评估和测试验收 |
| 大图体验 | 4K 图片标注操作保持连续响应 | 在目标设备上使用验收数据集实测 |
| 启动体验 | 启动后有可见状态并尽快进入界面 | 目标为 3 秒内出现可操作反馈 |

## 8. 验收场景

| 场景 | 前提 | 用户操作 | 预期结果 |
| --- | --- | --- | --- |
| 绿色启动与退出 | 已解压 Windows 或 Linux 包 | 启动应用、关闭网页、从托盘退出 | 界面可找回，退出后无应用后台进程残留 |
| 新用户首流程 | 已导入少量图片 | 描述目标并回答 Agent 追问 | 用户知道要标注什么，规则经确认后生效 |
| 阶段计划确认 | Agent 准备执行训练或数据处理 | 修改参数并确认执行 | Agent 复述最终计划，确认后才执行 |
| 实例分割标注 | 有已确认规则和一批图片 | 人工绘制、编辑并确认实例遮罩 | 只有已确认标注进入数据集 |
| 标注修正 | 存在错误或未完成标注 | 编辑遮罩、调整类别并重新确认 | 修正后的结果进入新的数据集版本 |
| 小样本训练 | 数据量少于建议值 | 发起实验训练 | 允许尝试，明确提示风险并展示训练状态 |
| 训练与评估 | 有已确认数据集版本 | 确认训练并查看结果 | 指标、失败案例、参数和数据版本可追溯 |
| 新图片测试 | 有候选模型 | 选择新图片识别 | 展示实例遮罩、类别和置信度，可保存结论 |
| 候选模型比较 | 至少两个训练结果 | 用同一批图片测试 | 能看出结果差异并选择当前候选模型 |
| 配置与隐私 | 配置模型服务并运行任务 | 检查界面、日志和交付包 | 密钥不泄漏，历史项目和会话不丢失 |
| 任务中断 | 训练或批量处理进行中 | 关闭网页、重新打开并请求停止 | 任务状态可恢复，停止结果真实准确 |
